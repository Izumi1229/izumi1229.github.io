## 博客运行时间
在主页的最下方，我增加了一个小小的运行时间计数器。
### HTML
计时器的 HTML 结构放在：'''src/components/Sidebar.astro'''

核心代码：
'''
<div class="site-copyright">
  <p>
    博客已运行
    <span id="blog-live-time">0 天 0 小时 0 分钟</span>
  </p>
</div>
'''
'''site-copyright'''：页脚区域的容器。
'''blog-live-time'''：计时器的显示位置，JavaScript会通过这个ID找到对应的HTML元素，再将计算结果写进去。

最初显示的时间只是占位内容，真正的运行时间需要交给JavaScript计算。
### JS
'''
// 设置博客的起始时间
const blogStartTime = new Date("填写博客起始日期");

// 计算博客运行时间
function updateBlogTime() {
  const now = new Date();

  // 计算已经过去的总分钟数
  const diff = Math.floor(
    (now.getTime() - blogStartTime.getTime()) / 60000
  );

  // 将总分钟数拆分成天、小时和分钟
  const days = Math.floor(diff / 1440);
  const hours = Math.floor((diff % 1440) / 60);
  const minutes = diff % 60;

  // 找到 HTML 中的计时器位置
  const timeElement = document.getElementById("blog-live-time");

  // 更新页面显示
  if (timeElement) {
    timeElement.textContent =
      `${days} 天 ${hours} 小时 ${minutes} 分钟`;
  }
}

// 页面加载后立即执行一次
updateBlogTime();

// 每隔一分钟重新计算一次
setInterval(updateBlogTime, 60000);
'''
① 设置博客起始时间
'''
const blogStartTime = new Date("填写博客起始日期");
'''
这里定义了博客开始计算运行时间的日期。可以按照YYYY-MM-DDTHH:mm:ss+08:00的格式填写，例如日期、具体时刻以及时区。以后如果想修改博客的纪念日期，只需要修改这里即可。

② 获取当前时间
'''
const now = new Date();
'''
new Date()会获取访问者当前设备的时间。每次运行计时函数时，都会重新获取一次当前时间，因此计时器不会停留在第一次打开网页时的结果。

③ 计算时间差
'''
const diff = Math.floor(
  (now.getTime() - blogStartTime.getTime()) / 60000
);
'''
'''getTime()'''会把日期转换成从1970年1月1日开始计算的毫秒数。用当前时间减去起始时间，就能得到两个日期之间相差的毫秒数。再除以 60000，就把毫秒转换成了分钟。

'''Math.floor()'''的作用是向下取整，只保留完整的分钟数。

④ 把总分钟数转换成天、小时和分钟
'''
const days = Math.floor(diff / 1440);
const hours = Math.floor((diff % 1440) / 60);
const minutes = diff % 60;
'''
这里用到了三个单位之间的换算关系：

*1天=24小时=1440分钟
*1小时=60分钟

例如，如果博客已经运行了3000分钟：

*天数：3000÷1440，向下取整为2天。
*小时：剩余120分钟，换算为2小时。
*分钟：剩余0分钟。

最终显示为：

博客已运行2天2小时0分钟

⑤ 将计算结果写回网页
'''
timeElement.textContent =
  `${days} 天 ${hours} 小时 ${minutes} 分钟`;
'''
'''document.getElementById()'''会找到HTML中对应的计时器元素。

'''textContent'''则负责修改这个元素内部显示的文字。

这样，JS算出来的时间就能出现在主页上。

⑥ 让计时器自动更新
'''
updateBlogTime();
setInterval(updateBlogTime, 60000);
'''
第一行让网页加载后立即计算一次，避免刚打开页面时仍然显示占位文字。第二行使用'''setInterval()'''设置定时执行，60000代表60000毫秒，也就是一分钟。

因此，计时器每隔一分钟就会重新计算一次，不需要手动刷新网页。

### 为什么使用JS
我的博客使用Astro构建，最终生成的是静态网页。静态网页本身不会自动计算时间，也不会因为过了一分钟就主动改变页面内容。所以这里使用 JavaScript，让浏览器在访问页面时完成时间计算。这样不需要服务器持续运行计时任务、数据库记录运行时间、每分钟向服务器发送请求，并且只要打开网页，浏览器就能自动计算并更新。
## 书影音游
我单独设计了一个「书影音游」分类，用来收录自己读过的书、看过的电影和剧集，以及接触过的游戏。这个页面更接近一个私人收藏馆。每一部作品都有自己的封面、基本信息和独立详情页，可以记录作品资料，也可以留下个人评价。整个功能基于Astro的静态页面生成机制实现，使用Markdown管理作品内容，通过Astro Layout统一详情页结构。
### Frontmatter
每部作品都使用独立的Markdown文件记录。文件开头通过Frontmatter定义作品的基本信息。

例如：
'''
---
layout: ../../../layouts/BlogPost.astro
title: "作品名称"
date: 2026-01-01
description: "一段简短的作品介绍"
category: 书影音游
type: book
rating: 4.5
cover: /images/works/example.jpg

originalTitle: "Original Title"
author: "作者"
translator: "译者"
publisher: "出版社"
distributor: "发行方"
publishDate: "出版日期"
pages: "页数"
---
'''
这里使用的是YAML Frontmatter，它允许在Markdown正文之前定义结构化数据。
### Astro Layout
为了让所有作品拥有一致的页面结构，我使用了Astro Layout。

核心文件：
'''src/layouts/BlogPost.astro
'''
作品详情页主要分为两个区域：'''WORK INFORMATION'''：作品基本信息。'''MY REVIEW'''：个人评价与阅读、观影或游玩感受。

### 作品资料展示
核心结构：
'''
<section class="work-archive">

  <div class="work-cover">
    <img
      src={frontmatter.cover}
      alt={frontmatter.title}
    />
  </div>

  <div class="work-details">

    <h1>{frontmatter.title}</h1>

    <p class="work-description">
      {frontmatter.description}
    </p>

    <ul class="work-info-list">
      {
        workInfo
          .filter(([label, value]) => value)
          .map(([label, value]) => (
            <li>
              <span>{label}</span>
              <span>{value}</span>
            </li>
          ))
      }
    </ul>

  </div>

</section>
'''
### 个人评价区域
核心结构：
'''
<section class="my-review">

  <h2>MY REVIEW</h2>

  <div class="review-body">
    <slot />
  </div>

</section>
'''
这里最重要的是Astro的<slot />。它的作用是将Markdown文件中的正文内容插入当前Layout指定的位置。因此，每部作品虽然共用同一个详情页模板，但正文内容完全独立。最终生成的页面会自动将这部分正文放入MY REVIEW区域。这样就实现了统一页面结构、独立作品内容的效果。
